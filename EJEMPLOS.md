## 💡 Consejos para Crear Tus Propios Ejemplos

### Combinación de Etiquetas
Puedes combinar múltiples etiquetas para crear efectos más complejos:

```
[sorpresa] ¡Oh no! [grito] ¡Cuidado con eso! [pausa] [triste] Demasiado tarde...
```

### Timing con Pausas
Usa `[pausa]` estratégicamente para crear suspense:

```
El ganador del premio es... [pausa] [sorpresa] ¡Juan Pérez!
```

### Transiciones Suaves
Cambia gradualmente entre emociones:

```
Empezamos felices... [risa] Pero poco a poco... [pausa]
La tristeza nos invade. [triste] [llanto]
```

### Énfasis Selectivo
Combina etiquetas con mayúsculas y signos de puntuación:

```
¡INCREÍBLE! [grito] ¡No puedo creerlo! [sorpresa]
```
